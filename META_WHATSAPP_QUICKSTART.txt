  🚀 SETUP STEPS (15 minutes)
═══════════════════════════════════════════════════════════════

□ STEP 1: Create Meta Developer Account (3 min)
  → Go to: https://developers.facebook.com
  → Create App → Business
  → App name: "Curexhealth Bookings"

□ STEP 2: Add WhatsApp Product (2 min)
  → In app dashboard: Add products
  → Find WhatsApp → Set up

□ STEP 3: Get Credentials (5 min)
  → Copy: Temporary Access Token
  → Copy: Phone Number ID
  → Add your WhatsApp number as recipient
  → Verify with code

□ STEP 4: Test from Meta Dashboard (2 min)
  → Send "Hello World" test message
  → Check your WhatsApp
  → ✅ Message received = API working!

□ STEP 5: Update Apps Script (5 min)
  → Open: Extensions → Apps Script
  → Replace code with: APPS_SCRIPT_META_WHATSAPP.js
  → Update lines 2-4 with your credentials:
    • META_ACCESS_TOKEN
    • META_PHONE_ID
    • RECIPIENT_PHONE
  → Save

□ STEP 6: Test from Apps Script (2 min)
  → Select: testWhatsApp
  → Click: Run
  → Check WhatsApp for test message

□ STEP 7: Deploy (2 min)
  → Deploy → New deployment → Web app
  → Copy new URL
  → Update .env file
  → Restart server

□ STEP 8: Test End-to-End (2 min)
  → Submit booking from website
  → Check: Sheet + WhatsApp
