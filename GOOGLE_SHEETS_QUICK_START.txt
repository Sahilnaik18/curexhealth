  ⚡ SUPER QUICK OVERVIEW (5 minutes)
═══════════════════════════════════════════════════════════════

1. CREATE GOOGLE SHEET
   → sheets.google.com
   → New sheet: "Curexhealth Bookings"
   → Add headers (see guide)

2. ADD APPS SCRIPT
   → Extensions → Apps Script
   → Paste script (from guide)
   → Save

3. DEPLOY WEB APP
   → Deploy → New deployment → Web app
   → Execute as: Me
   → Who has access: Anyone ⚠️
   → Copy URL

4. ADD TO PROJECT
   → Create .env file
   → Add: VITE_GOOGLE_SHEETS_URL=your_url
   → Save

5. RESTART & TEST
   → Stop server (Ctrl+C)
   → npm run dev
   → Test booking on website
   → Check Google Sheet for data 🎉
